# replaceAll() —— 替换所有匹配

> 签名：`String.prototype.replaceAll(regexp|substr, newSubstr|function): string`
> 适合场景：明确要"全换"时比 `replace()` + `g` 语义更清晰。ES2021 引入。

```javascript
// 1. 字符串替换
console.log("js is js".replaceAll("js", "JavaScript")); // "JavaScript is JavaScript"

// 2. 参数是正则时必须带 g 标志，否则抛错
try {
  "abc".replaceAll(/\d/, "*");
} catch (e) {
  console.log(e.name); // TypeError
}

// 3. 替换所有数字
console.log("a1b2c3".replaceAll(/\d/g, "*")); // "a*b*c*"

// 4. 合并连续空白
console.log("a b  c   d".replaceAll(/\s+/g, "_")); // "a_b_c_d"

// 5. 换行符转 <br>
console.log("line1\nline2".replaceAll("\n", "<br>")); // "line1<br>line2"

// 6. 忽略大小写替换所有
console.log("JS js Js".replaceAll(/js/gi, "JavaScript")); // "JavaScript JavaScript JavaScript"

// 7. 压缩连续重复的字符（反向引用 \1）
console.log("aaabbbccc".replaceAll(/(.)\1+/g, "$1")); // "abc"

// 8. 函数作为替换值
console.log("1 2 3".replaceAll(/\d/g, (d) => `[${d}]`)); // "[1] [2] [3]"

// 9. 去除所有 HTML 标签
console.log("<p>hello</p><br>".replaceAll(/<[^>]*>/g, "")); // "hello"

// 10. $$ 表示字面量 $ 符号
console.log("price".replaceAll("price", "$$100")); // "$100"
```

## 注意事项

- 传**正则**时必须带 `g` 标志，否则抛 `TypeError`；传**字符串**没有这个限制。
- 特殊符号（`$1`、`$&`、`$$` 等）的用法与 `replace()` 完全一致，见 06 篇的表格。

## 进阶例子（11–20）

```javascript
// 11. 下划线命名批量转驼峰
console.log("user_name user_age".replaceAll(/(\w+)_(\w+)/g, (_, a, b) => a + b[0].toUpperCase() + b.slice(1)));
// "userName userAge"

// 12. 驼峰批量转下划线
console.log("userName userAge".replaceAll(/([a-z])([A-Z])/g, "$1_$2").toLowerCase());
// "user_name user_age"

// 13. Unicode 属性转义：替换所有字母（u 标志）
console.log("a1b2c3".replaceAll(/\p{L}/gu, "x")); // "x1x2x3"

// 14. 替换所有 Emoji 为占位符
console.log("I 😊 you 🎉!".replaceAll(/\p{Extended_Pictographic}/gu, "[e]")); // "I [e] you [e]!"

// 15. 查表批量替换（敏感词过滤）
const dict15 = { bad: "***", ugly: "###" };
console.log("bad & ugly word".replaceAll(/\w+/g, (w) => dict15[w] ?? w)); // "*** & ### word"

// 16. 删除所有单行注释（gm 标志按行匹配）
console.log("// note1\ncode\n// note2".replaceAll(/^\/\/.*$/gm, "").trim()); // "code"

// 17. 全角空格与半角空格统一压缩
console.log("a　b  c".replaceAll(/[\s\u3000]+/g, " ")); // "a b c"

// 18. 短横线短语转标题格式
console.log("hello-world-foo".replaceAll(/-(\w)/g, (_, c) => " " + c.toUpperCase()));
// "hello World Foo"

// 19. 给文本里所有整数加千分位
console.log("价格 1234567 和 999".replaceAll(/\d+/g, (n) => n.replace(/\B(?=(\d{3})+(?!\d))/g, ",")));
// "价格 1,234,567 和 999"

// 20. 替换串里的 $& 会被展开为匹配内容，要输出字面量就用函数
console.log("hello".replaceAll("l", "[$&]"));       // "he[l][l]o"（$& 被展开）
console.log("hello".replaceAll("l", () => "[$&]")); // "he[$&][$&]o"（函数返回值按字面处理）
```
