# search() —— 返回第一个匹配位置的索引，无匹配返回 `-1`

> 签名：`String.prototype.search(regexp): number`
> 适合场景：只关心"匹配在哪/有没有匹配"，不关心匹配内容。

```javascript
// 1. 返回第一个匹配的位置
console.log("abc123".search(/\d/)); // 3

// 2. 无匹配返回 -1
console.log("abc".search(/\d/)); // -1

// 3. 忽略大小写
console.log("Hello JS".search(/js/i)); // 6

// 4. 忽略 g 标志：始终只返回第一个匹配的位置
console.log("a1b2".search(/\d/g)); // 1

// 5. 配合锚点判断协议
console.log("https://x.com".search(/^https?:\/\//)); // 0
console.log("ftp://x.com".search(/^https?:\/\//)); // -1

// 6. 特殊字符需要转义
console.log("price: $100".search(/\$/)); // 7

// 7. 中文字符的位置
console.log("hello world".search(/世界/)); // 6

// 8. 查找第一个元音字母
console.log("rhythm".search(/[aeiou]/)); // -1（没有元音）
console.log("hello".search(/[aeiou]/)); // 1

// 9. 查找第一个空白字符
console.log("a b c".search(/\s/)); // 1

// 10. 结合 ^ 判断是否以数字开头（返回 0 即开头）
console.log("9to5".search(/^\d/)); // 0
console.log("to5".search(/^\d/)); // -1
```

## 注意事项

- `search()` 会忽略 `g` 标志，永远只找第一个，也没有 `lastIndex` 状态问题。
- 只要判断"是否包含"，用 `test()` 或 `includes()` 更语义化；要位置就用 `search()`。

## 进阶例子（11–20）

```javascript
// 11. 定位第一个中文
console.log("hello世界".search(/[\u4e00-\u9fa5]/)); // 5

// 12. 第一个大写字母的位置
console.log("alllower".search(/[A-Z]/));     // -1（没有大写）
console.log("noCapitalHere".search(/[A-Z]/)); // 2（大写 C 在位置 2）

// 13. 检查连续空格（排版校验）
console.log("a  b".search(/ {2}/)); // 1
console.log("a b".search(/ {2}/));  // -1

// 14. 判断是否以字母开头（返回 0 表示开头就命中）
console.log("abc123".search(/^[a-zA-Z]/)); // 0
console.log("123abc".search(/^[a-zA-Z]/)); // -1

// 15. 判断是否以数字结尾（返回的是最后一个数字的索引）
console.log("abc123".search(/\d$/)); // 5
console.log("abc12a".search(/\d$/)); // -1

// 16. 第一个标点符号的位置（非字母、数字、空白）
console.log("wait, what?".search(/[^\w\s]/)); // 4

// 17. 多选分支：位置最靠前的获胜
console.log("hotdog has cat".search(/cat|dog/)); // 3（dog 更靠前）

// 18. 查找制表符
console.log("a\tb".search(/\t/)); // 1

// 19. 第一个非 ASCII 字符
console.log("ascii字符".search(/[^\x00-\x7f]/)); // 5

// 20. 用返回的索引做字符串切割
const s20 = "user@example.com";
const at20 = s20.search(/@/);
console.log(s20.slice(0, at20));  // "user"
console.log(s20.slice(at20 + 1)); // "example.com"
```
