# matchAll() —— 返回所有匹配（含捕获组详情）的迭代器

> 签名：`String.prototype.matchAll(regexp): Iterator`
> 适合场景：批量提取并需要捕获组、命名分组、`index` 等完整信息。ES2020 引入。

```javascript
// 1. 基本用法：返回迭代器，用展开运算符转数组
const it1 = "a1b2c3".matchAll(/\d/g);
console.log([...it1].map((m) => m[0])); // ["1", "2", "3"]

// 2. 正则必须带 g 标志，否则直接抛错
try {
  "abc".matchAll(/\d/);
} catch (e) {
  console.log(e.name); // TypeError
}

// 3. 每个结果都保留捕获组
const arr3 = [..."2024-01-15 和 2025-02-20".matchAll(/(\d{4})-(\d{2})-(\d{2})/g)];
console.log(arr3.map((m) => [m[1], m[2], m[3]]));
// [["2024", "01", "15"], ["2025", "02", "20"]]

// 4. 命名捕获组
const arr4 = [..."<div>box</div>".matchAll(/<(?<tag>\w+)>(?<text>[^<]*)<\/\1>/g)];
console.log(arr4[0].groups); // { tag: "div", text: "box" }

// 5. 每个结果的 index 属性
const arr5 = [..."a-b-c".matchAll(/-/g)];
console.log(arr5.map((m) => m.index)); // [1, 3]

// 6. 用 for...of 遍历（不需要展开）
for (const m of "hello @alice and @bob".matchAll(/@(\w+)/g)) {
  console.log(m[1]); // 依次输出 alice、bob
}

// 7. 提取 HTML 中所有链接的 href
const html7 = "<a href='x.com'>X</a><a href='y.com'>Y</a>";
console.log([...html7.matchAll(/href='([^']*)'/g)].map((m) => m[1]));
// ["x.com", "y.com"]

// 8. 提取查询字符串中的所有键值对
const qs8 = "name=Tom&age=18&city=Beijing";
console.log([...qs8.matchAll(/(\w+)=(\w+)/g)].map((m) => [m[1], m[2]]));
// [["name", "Tom"], ["age", "18"], ["city", "Beijing"]]

// 9. 一步转成 Map
const map9 = new Map([..."a=1&b=2".matchAll(/(\w+)=(\w+)/g)].map((m) => [m[1], m[2]]));
console.log(map9.get("a")); // "1"

// 10. 提取代码中的所有字符串字面量
const code10 = 'const a = "hello"; const b = "world";';
console.log([...code10.matchAll(/"([^"]*)"/g)].map((m) => m[1])); // ["hello", "world"]
```

## 注意事项

- 传入的正则**必须带 `g` 标志**，否则抛出 `TypeError`。
- 返回的是迭代器，只能消费一次；需要重复使用先转数组。
- 相比 `exec()` + `while` 循环，`matchAll()` 无 `lastIndex` 状态坑，写法更直观。

## 进阶例子（11–20）

```javascript
// 11. 提取 Markdown 链接的文本和 URL
const md11 = "[官网](https://a.com) 与 [文档](https://b.com/docs)";
console.log([...md11.matchAll(/\[([^\]]+)\]\(([^)]+)\)/g)].map((m) => [m[1], m[2]]));
// [["官网", "https://a.com"], ["文档", "https://b.com/docs"]]

// 12. 提取模板变量名
console.log([..."你好{{name}}，今年{{age}}岁".matchAll(/\{\{\s*(\w+)\s*\}\}/g)].map((m) => m[1]));
// ["name", "age"]

// 13. 提取所有年份并去重、排序
const years13 = [..."2019、2020、2020、2023".matchAll(/\d{4}/g)].map((m) => m[0]);
console.log([...new Set(years13)].sort()); // ["2019", "2020", "2023"]

// 14. 解析日志：时间戳 + 级别
const log14 = "2024-01-15 09:30 [ERROR] fail\n2024-01-15 09:31 [INFO] ok";
console.log([...log14.matchAll(/(\d{4}-\d{2}-\d{2} \d{2}:\d{2}) \[(\w+)\]/g)].map((m) => [m[1], m[2]]));
// [["2024-01-15 09:30", "ERROR"], ["2024-01-15 09:31", "INFO"]]

// 15. 提取 CSS 中的所有颜色值
const css15 = "color: #fff; bg: #123abc; border: rgb(1,2,3)";
console.log([...css15.matchAll(/#[0-9a-f]{3,8}|rgb\([^)]*\)/gi)].map((m) => m[0]));
// ["#fff", "#123abc", "rgb(1,2,3)"]

// 16. 解析 CSV 行（引号内包含逗号也不拆分）
const row16 = 'Tom,18,"Beijing, China"';
console.log([...row16.matchAll(/"[^"]*"|[^,]+/g)].map((m) => m[0].replace(/^"|"$/g, "")));
// ["Tom", "18", "Beijing, China"]

// 17. 提取中文及其位置
console.log([..."a你b好c".matchAll(/[\u4e00-\u9fa5]/g)].map((m) => [m[0], m.index]));
// [["你", 1], ["好", 3]]

// 18. 命名捕获组解析身份证号
const m18 = [..."身份证：110101199003077758".matchAll(/(?<area>\d{6})(?<birth>\d{8})\d{3}[\dX]/g)];
console.log(m18[0].groups); // { area: "110101", birth: "19900307" }

// 19. 查询字符串一步转对象
console.log(Object.fromEntries([..."name=Tom&age=18".matchAll(/(\w+)=(\w+)/g)].map((m) => [m[1], m[2]])));
// { name: "Tom", age: "18" }

// 20. 迭代器只能消费一次
const it20 = "a1b2".matchAll(/\d/g);
console.log([...it20].length); // 2
console.log([...it20].length); // 0（已耗尽）
```
