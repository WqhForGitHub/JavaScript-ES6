# test() —— 检测字符串是否匹配正则，返回 `true` / `false`

> 签名：`RegExp.prototype.test(str): boolean`
> 适合场景：快速校验（表单验证、格式检查），不关心匹配内容时使用。

```javascript
// 1. 检查字符串是否包含数字
console.log(/\d/.test("abc123")); // true

// 2. 检查字符串是否全为数字
console.log(/^\d+$/.test("12345")); // true
console.log(/^\d+$/.test("12a45")); // false

// 3. 忽略大小写（i 标志）
console.log(/hello/i.test("HeLLo World")); // true

// 4. 检查是否以 "https://" 开头
console.log(/^https:\/\//.test("https://example.com")); // true

// 5. 检查是否以 ".js" 结尾
console.log(/\.js$/.test("app.js")); // true

// 6. 中国手机号验证（1 开头，第二位 3-9，共 11 位）
console.log(/^1[3-9]\d{9}$/.test("13812345678")); // true

// 7. 检查是否包含中文字符
console.log(/[\u4e00-\u9fa5]/.test("hello 你好")); // true

// 8. 单词边界：检查是否出现独立的单词 "cat"
console.log(/\bcat\b/.test("concatenate")); // false
console.log(/\bcat\b/.test("a cat here")); // true

// 9. 检查是否包含特殊字符
console.log(/[!@#$%^&*]/.test("p@ssword")); // true

// 10. g 标志下 lastIndex 会前进，影响下一次 test 的结果
const reg10 = /\d/g;
console.log(reg10.test("a1")); // true（匹配到 "1"，lastIndex 变为 2）
console.log(reg10.test("a1")); // false（从位置 2 继续，匹配失败，lastIndex 重置为 0）
console.log(reg10.test("a1")); // true（从头开始，又能匹配到）
```

## 注意事项

- 只做校验时**不要加 `g` 标志**，避免 `lastIndex` 状态干扰复用同一个正则对象。
- 每次都写字面量（如 `/^\d+$/`）不会有这个问题，因为字面量每次求值会创建新对象（除了 ES5 后同一字面量在循环中的缓存行为，现代引擎中字面量正则的 lastIndex 每次重新初始化）。

## 进阶例子（11–20）：常用校验场景

```javascript
// 11. 邮箱格式验证
const emailReg = /^[\w.%+-]+@[\w-]+\.[\w.]{2,}$/;
console.log(emailReg.test("user.name+tag@example.com")); // true
console.log(emailReg.test("invalid@@com"));              // false

// 12. 密码强度：8-16 位，必须同时含大写、小写、数字（前瞻断言）
const pwdReg = /^(?=.*[a-z])(?=.*[A-Z])(?=.*\d)[a-zA-Z\d]{8,16}$/;
console.log(pwdReg.test("Abc12345")); // true
console.log(pwdReg.test("abc12345")); // false（缺少大写字母）

// 13. 用户名：4-16 位字母、数字或下划线，且以字母开头
console.log(/^[a-zA-Z]\w{3,15}$/.test("user_01")); // true
console.log(/^[a-zA-Z]\w{3,15}$/.test("1user"));   // false（数字开头）

// 14. 日期合法性（月 01-12，日 01-31）
const dateReg = /^\d{4}-(0[1-9]|1[0-2])-(0[1-9]|[12]\d|3[01])$/;
console.log(dateReg.test("2024-01-15")); // true
console.log(dateReg.test("2024-13-01")); // false（月份 13 不合法）

// 15. 纯中文姓名（2-6 位）
console.log(/^[\u4e00-\u9fa5]{2,6}$/.test("张三丰")); // true
console.log(/^[\u4e00-\u9fa5]{2,6}$/.test("张三3"));  // false（含数字）

// 16. IPv4 地址验证（每段 0-255）
const ipReg = /^((25[0-5]|2[0-4]\d|1\d\d|[1-9]?\d)\.){3}(25[0-5]|2[0-4]\d|1\d\d|[1-9]?\d)$/;
console.log(ipReg.test("192.168.1.1")); // true
console.log(ipReg.test("256.1.1.1"));   // false（256 超出范围）

// 17. 车牌号（省份汉字 + 字母 + 5-6 位）
console.log(/^[\u4e00-\u9fa5][A-Z][A-Z0-9]{5,6}$/.test("京A12345")); // true
console.log(/^[\u4e00-\u9fa5][A-Z][A-Z0-9]{5,6}$/.test("aA12345"));  // false

// 18. 反向引用：检查是否有连续重复的单词
console.log(/\b(\w+)\s+\1\b/i.test("this is is a test")); // true（is is）
console.log(/\b(\w+)\s+\1\b/i.test("this is a test"));    // false

// 19. 负向先行断言：整个字符串中不出现 "abc"
console.log(/^(?!.*abc).*$/.test("xyz"));  // true
console.log(/^(?!.*abc).*$/.test("xabc")); // false

// 20. Unicode 属性转义：检查是否含 Emoji（需要 u 标志）
console.log(/\p{Extended_Pictographic}/u.test("hello 😊")); // true
console.log(/\p{Extended_Pictographic}/u.test("hello"));    // false
```

> 提示：判断 Emoji 不要用 `\p{Emoji}`——数字 0-9 也具有 Emoji 属性，会误判；`\p{Extended_Pictographic}` 更准确。
