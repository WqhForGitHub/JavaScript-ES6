# match() —— 返回匹配结果的数组

> 签名：`String.prototype.match(regexp): Array | null`
> 适合场景：提取匹配内容。行为随 `g` 标志变化明显：
> - **无 `g`**：返回第一条完整匹配（含捕获组），相当于 `regexp.exec(str)`。
> - **有 `g`**：返回所有匹配的**字符串数组**（不含捕获组和详情）。

```javascript
// 1. 无 g：返回第一条匹配，捕获组在后面
console.log("2024-01-15".match(/(\d{4})-(\d{2})-(\d{2})/));
// ["2024-01-15", "2024", "01", "15", index: 0, ...]

// 2. 有 g：返回所有匹配的字符串数组
console.log("a1b2c3".match(/\d/g)); // ["1", "2", "3"]

// 3. 匹配所有单词
console.log("hello, world!".match(/\w+/g)); // ["hello", "world"]

// 4. 匹配所有邮箱
console.log("联系: a@b.com 或 c@d.com".match(/\w+@\w+\.\w+/g));
// ["a@b.com", "c@d.com"]

// 5. 忽略大小写批量匹配
console.log("JS js Js".match(/js/gi)); // ["JS", "js", "Js"]

// 6. 无匹配时返回 null（使用前要判空）
console.log("abc".match(/\d/)); // null

// 7. 匹配所有中文
console.log("hello 世界 world".match(/[\u4e00-\u9fa5]+/g)); // ["世界"]

// 8. 匹配所有 HTML 标签
console.log("<div><p></p></div>".match(/<[^>]+>/g));
// ["<div>", "<p>", "</p>", "</div>"]

// 9. 匹配所有十六进制颜色码
console.log("#fff #123abc #FF0000".match(/#[0-9a-f]{3,6}/gi));
// ["#fff", "#123abc", "#FF0000"]

// 10. 配合解构赋值
const [first10, ...rest10] = "one two three".match(/\w+/g);
console.log(first10); // "one"
console.log(rest10);  // ["two", "three"]
```

## 注意事项

- 需要**捕获组的批量匹配**时 `match()` 无能为力（`g` 模式下丢弃捕获组），请改用 `matchAll()`。
- 无匹配返回 `null` 而不是空数组，直接调用 `.map()` 会报错。

## 进阶例子（11–20）

```javascript
// 11. 统计字符出现次数
console.log("banana".match(/a/g).length); // 3

// 12. 提取所有数字并求和
console.log("a1b22c333".match(/\d+/g).map(Number).reduce((a, b) => a + b, 0)); // 356

// 13. 找出重复出现的单词
const words13 = "cat dog cat bird dog".match(/\w+/g);
const dup13 = words13.filter((w, i) => words13.indexOf(w) !== i);
console.log([...new Set(dup13)]); // ["cat", "dog"]

// 14. 提取所有中文词语
console.log("JavaScript 是 最流行的 语言".match(/[\u4e00-\u9fa5]+/g)); // ["是", "最流行的", "语言"]

// 15. 前瞻断言：提取所有后面跟 = 的属性名
console.log("<input type='text' required>".match(/[\w-]+(?==)/g)); // ["type"]

// 16. 无 g + i：返回第一条忽略大小写的完整匹配（含详情）
console.log("Hello World".match(/world/i)); // ["World", index: 6, ...]

// 17. 提取所有 img 的 src
console.log("<img src='a.png'><img src='b.png'>".match(/src='[^']*'/g));
// ["src='a.png'", "src='b.png'"]

// 18. 统计单词数量
console.log("The quick brown fox".match(/\b\w+\b/g).length); // 4

// 19. 提取语义化版本号
console.log("v2.13.4-release".match(/\d+\.\d+\.\d+/)[0]); // "2.13.4"

// 20. 参数传字符串会被转成等价正则（"-" 无特殊含义，安全）
console.log("2024-01-15".match("-")); // ["-", index: 4]
```

> 提示：`match("+")` 这类写法会把 `+` 当成量词，直接抛 `SyntaxError`，特殊字符要自己转义或改用 `includes()`。
